# IT Troubleshooting Basics
This repository is a collection of common IT troubleshooting scenarios and basic solutions. It is designed to demonstrate foundational technical support skills, problem-solving ability, and structured troubleshooting approaches.

## 🔧 Common Issues & Solutions

### 1. WiFi Connection Issues
**Problem:** Device cannot connect to WiFi  
**Steps Taken:**
- Verified WiFi is enabled
- Restarted router and device
- Checked network settings and password
- Updated network drivers (if applicable)

---

### 2. Mouse / Keyboard Not Working
**Problem:** Wireless mouse not responding  
**Steps Taken:**
- Checked batteries and power switch
- Re-paired Bluetooth or USB receiver
- Tested device on another computer
- Restarted system

---

### 3. Application Not Opening
**Problem:** Program fails to launch  
**Steps Taken:**
- Restarted computer
- Checked for updates
- Reinstalled application
- Verified system compatibility

---

### 4. Slow Computer Performance
**Problem:** System running slowly  
**Steps Taken:**
- Closed unused applications
- Checked task manager for high usage
- Restarted system
- Cleared temporary files
